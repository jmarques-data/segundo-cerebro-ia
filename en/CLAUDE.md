# Second Brain Rules

- Write everything in English.
- Every note starts with frontmatter containing `date` (YYYY-MM-DD), `tags` and `status`.
- Before editing an existing file, show the proposed change and wait for confirmation.
- Never delete files. When something is done, move it to `99-archive/` (keeping its original subfolder).
- Do not store passwords, bank details, ID documents or health data. If they show up, warn me and leave them out.
- When you create a note, add its link to the folder's README.md (showing the change first, since the README already exists).
- Use the templates `_project-template.md`, `_job-template.md` and `_video-template.md` when they apply.
