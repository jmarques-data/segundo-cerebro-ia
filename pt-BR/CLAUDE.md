# Regras do Segundo Cérebro

- Escreva tudo em português brasileiro.
- Toda nota começa com frontmatter contendo `data` (AAAA-MM-DD), `tags` e `status`.
- Antes de editar um arquivo existente, mostre a alteração proposta e aguarde confirmação.
- Nunca apague arquivos. Quando algo estiver concluído, mova para `99-arquivo/` (mantendo a subpasta de origem).
- Não registre senhas, dados bancários, documentos de identidade ou dados de saúde. Se aparecerem, avise e omita.
- Ao criar uma nota, adicione o link dela no README.md da pasta (mostrando a alteração antes, pois o README já existe).
- Use os modelos `_modelo-projeto.md`, `_modelo-vaga.md` e `_modelo-video.md` quando aplicável.
